# v0.6.0 Performance Audit

## Observation Engine Timing

Measured using `timing_observe_scale` (cargo test -- --ignored --nocapture).

| Processes | Iterations | Total Time | Per Call |
|-----------|-----------|------------|----------|
| 1000      | 1000      | 1.86 s    | 1.86 ms   |

Timing measured in debug (test) profile. Release profile will be significantly faster.

The timing test exists for baseline tracking only. No optimization work was performed because no bottleneck was demonstrated. If future profiling under real workloads reveals a bottleneck, optimization can be justified then.

## Sampling Cost

No sampler changes in v0.6.0. Sampling path identical to v0.5.13.

## Draw Regression

Draw path unchanged except for 4 extra match arms in `observation_to_line`. Each arm constructs a single `Line` with one `Span` — no measurable regression.

## Summary

- No speculative micro-optimizations remain
- Timing baseline recorded (debug profile): 1.86 ms/call at 1000 processes
- No draw regression
- No sampler regression
- All optimization deferred until profiling demonstrates a bottleneck
